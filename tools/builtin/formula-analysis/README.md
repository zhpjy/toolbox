# 公式计算

代入变量计算四则运算公式，支持括号、`+ - * /`、数字和变量名。

## 输入格式

工具有两个文本输入和两个文本输出，界面标签分别为 **公式**、**变量**、**公式代入**、**计算结果**：

1. **公式**：四则运算表达式，支持 `+` `-` `*` `/` `(` `)`、数字和变量名（字母或下划线开头）。无需 `公式` 前缀。
2. **变量**：以空格分隔的 `name:value` 或 `name=value` 对；无需 `变量` 前缀，可为空。

输出：

1. **公式代入**：将变量值代入后的公式。
2. **计算结果**：公式求值后的结果。

## 示例

```
公式：a+b+c/d*e
变量：a:1 b:2 c:3 d:4 e:5
```

输出：

```
公式代入：1+2+3/4*5
计算结果：6.75
```

## 安全

采用递归下降解析器实现表达式求值，禁止使用 `eval` 或 `Function` 构造器。
